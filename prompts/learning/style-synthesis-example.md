## 相似问句的条件对照

以下仍是虚构示范，不是本次来源。两段中的答话者是同一人：

```text
甲段：
“能借我一盏灯吗？”
“拿去，明早还我。”
他把灯递过来，又低头记账。

乙段：
“能再借一盏吗？”
“上回那盏还在你屋里。”
“我明天一起还。”
“还了再说。”
```

这不是“人物一向热心”与“人物一向冷硬”的冲突。甲段短答同意、补归还时间，再由递灯和继续记账收住；乙段先指出未归还的旧物，对方提出延期，答话者才以短句维持条件。两段都能学习简短接话，但后者的拒绝依赖未归还这一处境，不能从共同的借物题材推导所有求助都要先拒绝。也不能把甲段概括成“回应后必须低头记账”。

## 表达观察示例

以下选自作者模板，用于展示不同观察对象，不是要求在本次作品中凑齐的分类表。正式卡的原句仍从本次作品选择；这些示例没有本次sample_id，不能注册为来源。说明的是文字怎样组织，不是要求重演例中事件。

### 对白拆开与标签位置
```text
“老板，这我朋友。”
刘健也向沈浪打着招呼。
“他也想在这钓半天，行吗？”
```
前句介绍关系，中间动作标明说话者，后句才提出请求。可归纳为“[介绍]→[同一说话者的动作]→[请求及短问]”，不是每次对白都插动作；与先动作后开口、说完再写反应分别观察。

### 回声反问与追加疑问
```text
“老板，我们也是来钓鱼的。”
“钓鱼？”
沈浪指了指这头牛，用不确定的语气问道。
“用牛来拉？”
```
先重复对方关键词，再用动作指出疑点，末句补出具体不解。骨架为“[重复词]？→[疑点所指]→[具体疑问]？”，条件是上一句话与眼前所见存在待解释之处；不能简化成所有反问都表示震惊。

### 同一话轮内转向
```text
“也不贵，一天也才200块！而且他好像说还可以回鱼！等等...”
```
“而且”追加理由，“等等...”中断尚在展开的话。可学同一话轮怎样从顺接转向暂停；此例没有接下来的回应，不能补出暂停之后想通了什么。

### 口语、语气与语境错位
```text
“妈的，你要不说他心善，我都能把他当杀人犯看待！”
“你们信它就是引路鱼，我不信它就是酸菜鱼，让我来！”
```
前例用“你要不说……我都能……”把他人评价与自己的判断放在一句里；后例用“你们信／我不信”的对举更换称呼，末尾短命令转入行动。粗口、对举与命令各有作用，不把这些词本身当作所有角色必用词。

### 群口互相接话
```text
“老板，你什么饵料啊，镶了金边啊，两百一包！”
“耗子，说不定一包十几二十斤呢，不要一惊一乍的！”
“一斤一包，童叟无欺！”
“我靠，老板，你敲诈呢？”
```
报价引出夸张反问，另一人猜重量缓和，短答给出实际重量，下一句据此改变态度。无逐句动作标签仍有称呼与回应帮助辨认话轮；数量、说话者和顺序不能互换后仍称同一种安排。

### 名词短句与焦点前置
```text
废品血脉！
这钱，他不敢收！
```
前例以名词短语独立承载强调，后例把宾语提到判断前。骨架分别为“[被强调名词]！”和“[对象]，[人物][判断/动作]！”。同一骨架的多个用例不自动算多种句式，名词内容本身也不是写作规则。

### 信息交代与人物推断
```text
所谓空间法宝，便是内藏空间的法宝，能够将随身的物品放进去。
这应该是传说中的仙人指路，虽然罕见，但也不是没发生过，我们宗门曾经有一位弟子……
```
前例以“所谓……便是……”直接解释概念和用途；后例以“应该”提出判断，再用先例支持。学习信息如何交代时保留这种确定度差异，不能把推断统一改成叙述者已经证实的事实。

### 反应层次与叙述入口
```text
一时间，所有人都屏住了呼吸。
所有人皆是异常兴奋，如今他们已经是青云门弟子了……已经算是鲤鱼跃龙门了。
```
前例写共同生理反应，后例直接交代群体情绪及身份变化的意义。具体作品是否允许这种叙述入口应由该作品原文判定；示例不能强制它使用全知视角，也不能据默认限知删掉本书实际存在的旁白。
